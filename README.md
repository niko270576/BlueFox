# Blue Fox

Ένα ολόκληρο λειτουργικό σύστημα που ξεκινά από USB, σε πλήρη οθόνη.

## Αρχεία
| Αρχείο | Τι κάνει |
|---|---|
| `bluefox.py` | Το Blue Fox |
| `build-iso.sh` | Φτιάχνει το `BlueFox.iso` |
| `.github/workflows/build-iso.yml` | Λέει στο GitHub να τρέξει το `build-iso.sh` και να δημοσιεύσει το ISO |

## Πώς φτιάχνεται το ISO
Κάθε φορά που αλλάζει το `bluefox.py` ή το `build-iso.sh`, το GitHub χτίζει μόνο του νέο ISO
(καρτέλα **Actions**, περίπου 30–60 λεπτά). Το έτοιμο `BlueFox.iso` βρίσκεται στα **Releases → Assets**.

## Πώς μπαίνει σε USB
1. Κατέβασε το **Rufus** (rufus.ie) στα Windows.
2. Διάλεξε το USB (τουλάχιστον 8 GB) και το `BlueFox.iso`.
3. Στο **Persistent partition size** βάλε όσο χώρο θες για τα αρχεία σου (π.χ. 4 GB).
4. Πάτα **START** και, αν ρωτήσει, διάλεξε **ISO Image mode**.

## Πώς ξεκινά
Βάλε το USB, άνοιξε τον υπολογιστή και πάτα το πλήκτρο του boot menu (συνήθως **F12**, **F11**, **F9**, **Esc** ή **F2**).
Διάλεξε το USB. Το Blue Fox ανοίγει μόνο του.

- Τίποτα δεν γράφεται στον δίσκο του υπολογιστή· όλα μένουν στο USB.
- Πληκτρολόγιο: **Alt+Shift** αλλάζει Αγγλικά ↔ Ελληνικά.
- Wi-Fi: Ρυθμίσεις → Internet.
- Firefox και Brave είναι ήδη μέσα. Περισσότερα παιχνίδια και προγράμματα: Fox Store → Εφαρμογές υπολογιστή.

Το Blue Fox τρέχει πάνω σε μια μικρή βάση Debian (ελεύθερο λογισμικό).
